Icon font

Edit the project's icon font

This page builds the icon font and its Dart class from the drawings in tool/icons/svg, as set in tool/icons/icons.json. Nothing to install.

  1. Click Open project folder and choose the root of the repository (the folder that contains tool/icons).
  2. Add an icon: drop an SVG on the page. Replace one: select it, then drop the new SVG on it or use Replace drawing.
  3. Check the previews and the size, then click Save to project and commit the changed files.

Every icon keeps its code forever, so saving never breaks existing icons. Use Edge or Chrome (other browsers download the files instead of saving them in place).
